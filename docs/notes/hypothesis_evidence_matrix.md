# 青木まりこ現象｜仮説・証拠対応表（2026-10-19）

> **暫定的な卒業研究メモ。** 本研究で比較するのは、異なる調査設計・指標の**対応関係と限界**であり、3資料を一つの標本として統合するメタ分析や、書店での便意の因果効果の推定ではない。結論・題目は指導教員との相談後に確定する。

## 1. 研究上の問いと結論の到達範囲

**大きな問い**：青木まりこ現象は書店に特有なのか。滞在時間・行動や個人差は説明に役立つか。

**現段階で実際に答えられる問い**：
1. 書店外で、類似する**トイレ欲求**を経験したとする報告はあるか。
2. 書店と図書館の**観察上の滞在時間**、別の米国統計での**施設分類別の日誌上の活動時間**にはどんな分布があるか。
3. **お通じの悩みの有無**と、書店で便意を感じた**自己申告経験**との間に、公表集計上どんな関連があるか。

**直接には答えられない問い**：書店と他施設で同じ定義の便意が生じる確率の比較、書店に限って便意が生じる回答者の割合、滞在時間・匂い・心理状態などの因果効果。

**比較上の原則**：
- Aの便意経験率とAの他施設のトイレ欲求割合を、同一アウトカムの施設間発生率として直接比較しない。
- Bの「滞在時間」とCの「同日・施設分類別の活動時間合計」を同一指標として比較しない。国・時代・対象母集団も異なる。
- Cの加重平均は**その分類に活動記録がある人の日誌だけに条件付けた平均**。非訪問者の0分を含まず、カテゴリ間の人数は排他的でない。
- A・B・Cの数字をプールして一つの推定値を作らない。調査の直接性や因果推論の証拠の強さを標本サイズだけで判断しない。

### 結論ラベルの意味
- **未判定**：現有データでは仮説に対応するアウトカム・比較・時間順序が不足し、支持・棄却を判断できない。「差がない」「仮説が誤り」とは言わない。
- **未調整の関連を確認**：公開表の条件付き経験割合に差が記載されているという意味。標本の代表性、有意差、原因は保証しない。
- **H1の注意**：他施設での「トイレ欲求」が存在することは言えるが、排尿欲求と便意の区別が不明なため、書店以外でも同じ現象が生じることの厳密な実証にはならない。

## 4. 出典ごとに論文で書けること／書けないこと

### A 森永乳業
**書ける**：公表調査で書店の便意経験29.8%（n=1,000）、他施設のトイレ欲求25.8%（n=1,000）が報告された。お通じの悩みあり／なしで書店の便意経験率に26.8ポイント差（46.0%対19.2%）がある。

**書けない**：書店は他施設より便意が起きやすい／他施設でも書店と同じ便意が生じる／お通じの悩みが現象を引き起こす。29.8%と25.8%の差に統計的意味を与えない。

### B 松田
**書ける**：2館・2店で観察された40人の滞在時間の記述的差。探索的個人単位検定の結果（p=0.273、クラスター非考慮）を限定つきで紹介できる。

**書けない**：書店で便意が起こる原因が滞在時間ではない／書店と図書館の滞在時間に差が存在しない。母集団への一般化もしない。

### C ATUS
**書ける**：米国2023〜2025年の、活動が記録された施設分類別**日誌1日当たり活動時間**の分布・条件付き加重平均。

**書けない**：「書店での滞在時間は60.68分」「書店と図書館の便意発生率に差がある」「米国データから日本の青木まりこ現象を実証した」。

## 5. 卒論で使える暫定的な考察（過剰解釈を避けた文案）

> 森永乳業（2024）の公表調査では、書店で便意を感じる経験だけでなく、書店以外の場所でトイレに行きたくなる経験も報告されていた。ただし両設問は測定対象が一致しないため、本研究資料から書店での便意の特有性を直接判定することはできない。一方、同調査では、お通じに悩みがある群ほど書店での便意経験を報告する割合が高かった。これは身体的な個人差に関する仮説を検討する手掛かりとなるが、観察研究の公表集計から因果関係は推定できない。松田（2003）とATUSの時間データは、施設での行動時間を比較する補助資料となるものの、便意が未観測であり、滞在時間仮説の検証結果と見なすことはできない。

これは**暫定的な資料の統合的解釈**で、実証済みの原因説や施設間の厳密な効果量ではない。
