# 青木まりこ現象｜仮説・証拠対応表（2026-10-19）

> **暫定的な卒業研究メモ。** 本研究で比較するのは、異なる調査設計・指標の**対応関係と限界**であり、3資料を一つの標本として統合するメタ分析や、書店での便意の因果効果の推定ではない。結論・題目は指導教員との相談後に確定する。

## 1. 研究上の問いと結論の到達範囲

**大きな問い**：青木まりこ現象は書店に特有なのか。滞在時間・行動や個人差は説明に役立つか。

**現段階で実際に答えられる問い**：
1. 書店外で、類似する**トイレ欲求**を経験したとする報告はあるか。
2. 書店と図書館の**観察上の滞在時間**、別の米国統計での**施設分類別の日誌上の活動時間**にはどんな分布があるか。
3. **お通じの悩みの有無**と、書店で便意を感じた**自己申告経験**との間に、公表集計上どんな関連があるか。

**直接には答えられない問い**：書店と他施設で同じ定義の便意が生じる確率の比較、書店に限って便意が生じる回答者の割合、滞在時間・匂い・心理状態などの因果効果。

**比較上の原則**：
- Aの便意経験率とAの他施設のトイレ欲求割合を、同一アウトカムの施設間発生率として直接比較しない。
- Bの「滞在時間」とCの「同日・施設分類別の活動時間合計」を同一指標として比較しない。国・時代・対象母集団も異なる。
- Cの加重平均は**その分類に活動記録がある人の日誌だけに条件付けた平均**。非訪問者の0分を含まず、カテゴリ間の人数は排他的でない。
- A・B・Cの数字をプールして一つの推定値を作らない。調査の直接性や因果推論の証拠の強さを標本サイズだけで判断しない。

### 結論ラベルの意味
- **未判定**：現有データでは仮説に対応するアウトカム・比較・時間順序が不足し、支持・棄却を判断できない。「差がない」「仮説が誤り」とは言わない。
- **未調整の関連を確認**：公開表の条件付き経験割合に差が記載されているという意味。標本の代表性、有意差、原因は保証しない。
- **H1の注意**：他施設での「トイレ欲求」が存在することは言えるが、排尿欲求と便意の区別が不明なため、書店以外でも同じ現象が生じることの厳密な実証にはならない。

## 4. 発表で伝えること・今後確認すること

- **森永乳業**：公開集計を読み解いた結果。個票を独自分析したわけではなく、他施設との便意率の直接比較もできない。
- **松田**：本研究で40件を再集計した結果。施設数が少なく、便意も測っていない。
- **ATUS**：本研究で米国の公開個票を二次分析した結果。書店単独のデータでも、1回の訪問時間でもない。
- したがって、**書店特有性と原因は未判定**。お通じの悩みと書店での経験については、公表集計上の未調整の関連が確認できる。

教授への相談点：公開資料の評価を主軸とし、松田・ATUSを時間に関する補助分析として位置付けてよいか。今後同じ設問で施設別に調べる必要がある。
