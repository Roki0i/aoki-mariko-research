# 青木まりこ現象・滞在時間比較：第一回分析結果

松田千春（2003）「情報探索におけるブラウジング行動：図書館と書店における行動観察を基にして」『Library and Information Science』49, pp.1–31（表5–8）

原論文PDF：https://www.libinformsci.com/10.46895/lis.49.1/data/index.pdf

## データ
- 図書館A・B、書店C・Dの各10名、合計40名。原論文の表5～8より滞在時間を転記。
- 対象は2002年の行動観察。青木まりこ現象や便意を測定した研究ではない。

## 探索的統計分析
- Mann–Whitney U検定（図書館20人 vs 書店20人、両側）：U = 241.0, p = 0.273
- Cliff’s delta（図書館−書店）= 0.205
- Kruskal–Wallis（4施設）：H = 4.014, p = 0.260
- 平均の差（図書館−書店）=16.73分、中央値の差=2.70分

## 解釈
- 図書館側の平均は高いが、中央値の差は小さい。図書館Aの90分超の3名が平均を大きく押し上げている。
- 個人単位の探索的検定では5%水準の有意差は認められない。「差がない」と証明したわけではない。
- 施設数が2館・2店しかなく、同じ施設内の観察者は独立した標本とは見なせない場合がある。検定のp値は参考値。
- 原論文は書店Cで約1時間滞在した人を追跡し切れず、データに反映されていないと明記している（原論文p.12）。選択バイアスに注意。
- **便意が測定されていないため、滞在時間説も書店特有説も、このデータ単独では肯定・否定できない。**

## 発表用まとめ
書店と図書館で観察された40人の滞在時間を再集計したところ、平均は図書館35.0分、書店18.2分でした。一方、中央値は23.2分と20.5分で、探索的検定のp値は0.273でした。施設数が少なく、観察漏れもあるため、一般化には注意が必要です。また、便意は記録されておらず、この結果から原因を判断することはできません。ATUSの分析は別の国・別の指標を使った補助資料として扱います。
